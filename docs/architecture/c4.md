# Arquitetura (Modelo C4)

## Nível 1 — Contexto

```mermaid
C4Context
    title Sentinela — Contexto do sistema

    Person(dev, "Desenvolvedor", "Abre Pull Requests")
    Person(sec, "Revisor de segurança", "Faz a triagem dos achados no dashboard")
    System(sentinela, "Sentinela", "Plataforma SAST: analisa código, aplica o Security Gate e mostra métricas")
    System_Ext(github, "GitHub", "Repositório, Pull Requests, Actions e code scanning")
    System_Ext(ollama, "Ollama (Llama 3)", "LLM local para triagem e correção")

    Rel(dev, github, "push / Pull Request")
    Rel(github, sentinela, "Actions executa a CLI ou envia o código para a API")
    Rel(sentinela, github, "comentário no PR, status do job, SARIF")
    Rel(sentinela, ollama, "pede veredito e correção por achado", "HTTP/JSON")
    Rel(sec, sentinela, "consulta dashboard, marca falso positivo / risco aceito")
```

## Nível 2 — Containers

```mermaid
C4Container
    title Sentinela — Containers (docker-compose.yml)

    Person(user, "Usuário")
    System_Ext(gh, "GitHub Actions", "Security Gate em cada PR")

    Container_Boundary(platform, "Sentinela") {
        Container(cli, "CLI sentinela", "Python", "Scan local/CI, política do gate, SARIF e Markdown")
        Container(api, "API + Dashboard", "FastAPI, JS + Chart.js", "Recebe scans, expõe achados, métricas e relatórios")
        ContainerQueue(redis, "Redis", "Broker Celery", "Filas: analysis e ai")
        Container(wa, "worker-analysis", "Celery", "Tree-sitter, regras, taint, segredos, Bandit")
        Container(wi, "worker-ai", "Celery", "Triagem de falso positivo e correção via LLM")
        ContainerDb(pg, "PostgreSQL", "SQLAlchemy + Alembic", "Projetos, scans, achados, decisões de revisão")
    }
    System_Ext(ollama, "Ollama", "Llama 3 local")

    Rel(gh, cli, "executa")
    Rel(cli, api, "POST /api/scans (opcional)", "HTTPS")
    Rel(user, api, "dashboard / upload .zip", "HTTPS")
    Rel(api, pg, "lê/grava")
    Rel(api, redis, "enfileira analyze")
    Rel(redis, wa, "analyze / finalize")
    Rel(redis, wi, "assess (1 por achado)")
    Rel(wa, pg, "grava achados e gate")
    Rel(wi, pg, "grava veredito da IA")
    Rel(wi, ollama, "/api/generate", "HTTP/JSON")
```

## Nível 3 — Componentes do motor de análise

```mermaid
flowchart LR
    src[Arquivo .py / .js / .java] --> ts[Tree-sitter<br/>parser da linguagem]
    ts --> ad[LanguageAdapter<br/>python · javascript · java]
    ad --> rules[Motor de regras<br/>YAML declarativo]
    ad --> sec[Detector de segredos<br/>formato + nome + entropia]
    ad --> taint[Taint analysis<br/>fonte → sanitizador → sink<br/>+ resumo entre funções]
    rules --> merge[Fusão de achados<br/>mesma linha + mesma CWE]
    sec --> merge
    taint --> merge
    merge --> bandit[Bandit<br/>2º motor independente]
    bandit --> ctx[Contexto de código<br/>segredos mascarados]
    ctx --> fp[Fingerprint estável]
    fp --> out[(Achados)]
```

O `LanguageAdapter` é o ponto central do desenho: ele responde, para cada
linguagem, às mesmas perguntas ("qual o nome qualificado desta chamada?",
"este argumento é constante?", "que variável esta atribuição define?").
Regras e taint analysis são escritas **uma vez** sobre esse contrato e
funcionam nas três linguagens. Adicionar uma linguagem é escrever um
adaptador e um arquivo YAML de regras.

## Pipeline assíncrono

```mermaid
sequenceDiagram
    participant C as CLI / Dashboard
    participant A as API
    participant R as Redis
    participant W1 as worker-analysis
    participant W2 as worker-ai
    participant L as Ollama
    participant D as PostgreSQL

    C->>A: POST /api/scans (arquivos)
    A->>D: scan "queued" + arquivos
    A->>R: analyze(scan_id)
    A-->>C: 202 {id, status: queued}
    R->>W1: analyze
    W1->>D: achados, scan "ai_review"
    W1->>R: chord(assess × N) → finalize
    par um por achado
        R->>W2: assess(achado)
        W2->>L: prompt (código + caminho do dado)
        L-->>W2: veredito + correção (JSON)
        W2->>D: grava análise da IA
    end
    R->>W1: finalize
    W1->>D: gate + scan "completed"
    C->>A: GET /api/scans/{id} (polling)
```
